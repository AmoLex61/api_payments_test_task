
## Запуск

Python 3.13, команды выполнять из папки проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 payment_sandbox.py
```

## В другом терминале:

```bash
source .venv/bin/activate
curl http://127.0.0.1:8080/health
python -m pytest -v
```

## API

Проверены повтор с тем же ключом, конфликт тела, разные ключи, retry после 500,
валидация суммы/валюты и обязательного ключа, GET платежа, health и фильтр debug.
 Через debug проверяется количество операций,
а в сценариях повторов - также их ID.

Результат: **7 passed, 4 failed**. Падения связаны с тремя дефектами:
конфликт ключа, дубль после 500, приём нулевой/отрицательной суммы.
Подробности в BUG_REPORTS.md.
Проверки null, нечисловой и отсутствующей суммы не включены; GET проверяет код и ID.

## Сверка CSV

Нужен SQLite CLI. База временная, CSV не меняются.

```bash
sqlite3 :memory: < reconciliation.sql
```


| ref id  | У нас | У партнёра | Что проверить |
| R007 | 3000 USD, success | Нет | Полноту выписки и подтверждение операции |
| R099 | Нет | 8000 USD, success | Источник ref и наш журнал операций |
| R008 | 45000 RUB, success | 44500 RUB, success | Причину разницы 500: комиссии, первичные документы |
| R006 | 30000 RUB, pending | 30000 RUB, success | Подтверждение расчёта и доставку обновления статуса |
| R009 | Одна запись, 2500 USD, success | Две одинаковые записи, 2500 USD, success | Дубль выгрузки или две операции: запросить идентификаторы у партнёра |

Сначала SQL находит дубли, затем DISTINCT убирает одинаковые финансовые варианты
из сравнения, чтобы JOIN не размножал строки. Разные варианты одного ref сохраняются.
Дубль строки не доказывает двойное списание. Корректировки - после выяснения причины,
ни одну сторону заранее не считаем правильной. 

При большем времени: Одновременные запросы с одним ключом: отправить два запроса одновременно и убедиться,
что сервер создал один платёж. Сейчас запросы идут последовательно.
Повтор после рестарта: создать платёж, перезапустить сервис и повторит запрос с прежним ключом. 
Проверить, сохранилась ли защита от дублирования.
